Known issues — please read before installing

Users have reported “Playback engine unavailable”, titles that never start playing, and storage leftovers after playback or cleanup. Versions 1.0.18 and 1.0.19 fix the causes we reproduced, but these reports are not confirmed resolved on users’ computers. Bundled engines and build checks do not guarantee successful playback or complete cleanup on your computer, and every source depends on other people still sharing it.

The 1.0.21 startup fix follows a report that Akflix opened to a black window after updating to 1.0.20. We reproduced it on a Mac: storage left full by older versions’ catalog cache made saving the profile at launch fail, so the app never appeared. Akflix now trims that re-downloadable cache while keeping your profile, watch history, settings and captions, keeps running when storage is full, and shows what went wrong instead of a blank window if startup still fails. Playback and download code is unchanged from 1.0.19.

The 1.0.20 design update gives Akflix a black-and-white interface, a new logo and app icon, calmer motion that respects Reduce Motion, clearer keyboard focus and errors that are easier to spot. It removes a second menu-bar icon that had no menu, shows the installed version in Settings, no longer says “Wi-Fi ready” on the stream card when nothing was checked, and shows an error with Try again when the catalog cannot load. Playback and download code is unchanged from 1.0.19, so the reports above still apply.

The 1.0.19 playback update follows reports that Game of Thrones and The Walking Dead would not play. A source missing the chosen episode no longer leaves an endless spinner while a whole season pack downloads: Akflix tries the next source or says what was wrong. A listing that points at a spin-off (Tales of the Walking Dead) is no longer played as the episode you chose, Russian and Polish dubbed releases are no longer picked as English, and MP4 files the built-in player cannot decode (HEVC tagged hev1) or play with sound (DTS audio) switch to the conversion stream automatically. These changes were checked with automated tests, generated media and source listings, not by playing those shows, and an episode still cannot play when nobody is sharing it.

The 1.0.18 playback reliability update resumes titles the engine had paused instead of buffering forever, gives every new stream its own folder so empty files from a failed attempt no longer block that release, keeps the engine’s state on the drive you chose for media so a full startup disk no longer stops every stream, keeps the window responsive while a stream is prepared, and stops one failed cleanup from hiding new streams. Keep offline and saved season episodes are no longer removed during playback. These fixes were verified with automated tests on generated media and one public-domain film, not on every computer or source. Leftover files from older versions are not deleted automatically. Release notes and SHA-256 checksums

Good to know

Straight answers.

No mystery dependencies or fake promises about how peer networks behave.

Do I need Jellyfin, Docker, or qBittorrent?

No. The Mac and Windows builds include their playback engine and FFmpeg. Jellyfin and external qBittorrent connections are optional advanced settings.

Does Watch Now download the whole movie first?

No. Akflix prioritizes the selected video and streams it through a seekable local URL. Temporary pieces are cached during playback and are intended to be removed afterward, but storage leftovers have been reported and cleanup is not confirmed fixed. Download is a separate option.

Can playback always be Netflix-instant?

A hosted or debrid-cached HTTP link can start almost immediately. A public peer source cannot be guaranteed instant because its speed depends on metadata, reachable peers, seeders, and your connection. Akflix removes avoidable waiting, but it cannot manufacture a healthy peer.

Does it support shows?

Yes. Choose any season and episode before Watch Now. When an episode finishes, Akflix can automatically find and start the next one, including the first episode of the following season.

Can Akflix fix bad captions?

Both platforms support subtitle tracks and manual timing adjustments. Private English caption generation and automatic dialogue matching are currently Mac-only.

Which computers are supported?

Download the DMG for an Apple-silicon Mac running macOS 11 or later, or the EXE/MSI for Windows 10/11 on a 64-bit Intel or AMD PC. Native Windows ARM, Intel Mac, and Linux standalone installers are not part of this release.
